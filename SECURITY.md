# Security

Report suspected vulnerabilities in this fork privately using
[GitHub vulnerability reporting](https://github.com/otpki/circl/security/advisories/new).
Do not disclose them in public issues or pull requests. Include the affected
commit or version, a minimal reproduction using synthetic inputs, and the impact.
Maintainers must enable private vulnerability reporting before publication.

If the issue also affects unmodified Cloudflare CIRCL, follow
[Cloudflare's security policy](https://github.com/cloudflare/circl/security/policy)
to coordinate disclosure with upstream.

Fixes to this fork target the `iogo` branch. This fork does not establish a
separate security support commitment for older upstream releases. The upstream
experimental-cryptography disclaimer in the README continues to apply.
